GET vs POST Jwb : Mengapa ketika menggunakan method GET transfer itu sangat berbahaya dibandingkan menggunakan method POST karna method GET itu terlihat data transfernya di Alamat url dan ini sangatlah tidak aman, namun ketika kita transfer menggunakan method POST itu sudah aman karna ketika proses transfer itu langsung mengarah ke server dan tanpa memperlihatkannya ke Alamat url Memperbaiki konfigurasi database Jwb : Tahapan perbaikan Cek file .env, bagian DB_DATABASE itu sesuai dengan database yang ada Buat database (jika belum ada) di phpmyadmin dengan cara CREATE DATABASE db_acara; Periksa data ini juga ( DB_USER, DB_HOST, DB_PASSWORD) itu sudah sesuai misal nama user dan password harus disesuaikan dengan punyamu Jalankan perintah ini gunanya untuk menghapus config sebelumnya menjadi config baru dibuat Php artisan config:clear Jalankan ulang migrasi dengan perintah Php artisan migrate Merancang route dengan minddleware Jwb : //harus login Route::middleware(‘auth’)->group(function () { Route::get(’/kategori’, [KategoriController::class, ’index’]); Route::post(’/kategori/store’, [KategoriController::class, ’store’]); });
